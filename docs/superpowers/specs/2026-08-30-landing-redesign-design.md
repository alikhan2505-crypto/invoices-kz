# Редизайн главного лендинга (src/app/page.tsx) — дизайн

**Дата:** 2026-08-30
**Файл:** `src/app/page.tsx` (единственный файл; лендинг — client-компонент со встроенным `COPY` словарём на 3 языка)

## Контекст и цель

Founder вводит новый платный продукт — Kaspi Cashier API (для разработчиков) — и хочет, чтобы Kaspi Bot и AI-агент наконец получили полноценную промо-подачу на главном лендинге, вместо устаревшей заглушки "Скоро". Живой UX-аудит того же дня (коммиты `4c9290d..e982aea`) уже поправил цвета/контраст/доступность; этот спек — следующий шаг, чисто контентный/структурный редизайн двух секций.

Найдено при аудите: секция "Возможности" (`#features`) — шаблонная карточная сетка (icon+заголовок+текст), прямо запрещённая правилами дизайн-системы проекта. Секция "Скоро" (`soon`) числит Kaspi Bot как "Скоро для всех" — фича давно живая (репрайсер + 8 модулей). Обе секции меняются в этом спеке.

Kaspi Cashier API — по итогам сегодняшнего решения о ценах — отдельный платный продукт для другой аудитории (разработчики, не ИП/ТОО-бухгалтерия). Получает свою страницу (отдельный спек/проект, не этот). На этом лендинге про него — только неброская ссылка.

## Секция 1: Kaspi Bot / AI-агент (замена `soon`)

Визуально утверждено через visual companion (`section-combined-v2.html`, брейнсторм-сессия 2026-08-29/30): один блок, вкладки сверху переключают продукт, крупная цифра-якорь слева, анимированный демо-мокап справа. Framer-motion `fade-swap` при смене вкладки (не CSS `@keyframes`-строка из мокапа — переносится на framer-motion `AnimatePresence`/`motion.div`, чтобы соответствовать остальному файлу, который уже целиком на framer-motion).

**Заголовок:** «Ещё два сотрудника, которым не нужна зарплата»
**Подзаголовок:** «Kaspi Bot держит цены под контролем, AI-агент отвечает клиентам — 24/7, без вашего участия.»

**Вкладка 1 — Kaspi Bot** (активна по умолчанию):
- Цифра: **«10 мин»**
- Подпись: «между проверками цен конкурентов — Kaspi Bot держит вас на первой позиции без ручной работы»
- Демо-карточка: строка "Ваша цена" / "Конкурент" → `15 000 ₸` / `14 500 ₸ ↓`, статус-индикатор «проверка каждые 10 минут, без вашего участия» (пульсирующая точка, `@keyframes typing-dot` из мокапа)

**Вкладка 2 — AI-агент:**
- Цифра: **«5₸»**
- Подпись: «за автоответ клиенту в WhatsApp, Instagram, Telegram и на сайте»
- Демо: печатающийся чат — входящее «Здравствуйте, работаете завтра?», индикатор набора текста (3 точки, ~1.4с), затем ответ «Да, с 9:00 до 19:00 🙂»

**Честность цифр:** «10 мин» — реальный интервал проверки цен (это техническая механика продукта, не маркетинговая метрика — не нужно измерять/доказывать). «5₸» — реальная константа из кода (`AI_AGENT_CREDIT_PRICE_TENGE`). Никаких процентов/выдуманной статистики (изначальный "-17%" в мокапе был плейсхолдером и не переносится).

**Цвета:** переиспользовать уже задепложенную палитру после сегодняшнего контраст-фикса — `COLOR.violet` (#6E5ED8) для активной вкладки, `COLOR.teal`/`#5EEAD4` для акцентной цифры и статус-точки (тот же тон, что в hero H1, уже проверен на контраст), фон секции — тот же `COLOR.ground` (#0a0d1f) с уже существующими `AmbientBlobs`, а не новый радиальный градиент из мокапа (чтобы не плодить второй визуальный язык на одной странице).

**Reduced motion:** печатающийся чат и пульсация статус-точки — только для `!prefers-reduced-motion`; при reduced motion показываем финальное состояние (ответ уже показан, точка статична) без анимации переключения вкладок (мгновенный кроссфейд вместо анимации).

## Секция 2: Возможности (переформат `features`)

Тот же `features[]` массив (5 пунктов), новая вёрстка вместо `grid`:

Не karточки, не одинаковые по высоте блоки — просто список строк.

**Правка контента:** пункт «Kaspi API и вебхуки» (`icon: 'api'`) — текст описания меняется с «...документация — в разделе «Kaspi API»» на «...подробности и тарифы — на странице Cashier API», со ссылкой на маршрут `/cashier-api`. Остальные 4 пункта (invoice, kaspi, esign, contract) — текст без изменений.

## UX/UI QC-заметки (по итогам проверки ui-ux-pro-max)

Мокап `section-combined-v2.html` был одобрен визуально, но это прототип для брейнсторма, а не финальный код — два момента нужно поправить при реализации:

1. **Touch target вкладок.** Пилюли `.v2-tab` в мокапе (`padding:9px 20px; font-size:13px`) дают высоту тапа ~34px — меньше 44×44px, которые этот проект уже соблюдает как базовую норму (тот же стандарт, что применили в сегодняшних коммитах `a42a67b`/`366074b` для истории и иконок). В реализации у вкладок должен быть `min-height: 44px` с центрированием текста, а не буквальные паддинги из мокапа.
2. **Убрать декоративную бесконечную анимацию.** `glow-pulse` (бесконечный пульсирующий box-shadow вокруг демо-карточки, 3.5s infinite) — чисто декоративная бесконечная анимация без функционального смысла; такие оставляют только для индикаторов загрузки/состояния. Функциональный пульсирующий индикатор («проверка каждые 10 минут» / typing-dot) — оставить, он отражает реальное состояние. Декоративный `glow-pulse` на всей карточке — убрать.

Остальное в мокапе уже соответствует норме: длительность переключения вкладок (0.35s) укладывается в диапазон 150–400ms для сложных переходов; используются только `transform`/`opacity` (кроме убираемого `glow-pulse`); `prefers-reduced-motion` уже учтён в разделе "Reduced motion" выше. Структура секций (демо-мокап → фичи-брейкдаун → CTA) соответствует паттерну "Product Demo + Features" — менять порядок секций не нужно.
