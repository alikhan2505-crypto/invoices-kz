## Как было устроено

Один домен `invoices.kz`, одно верхнее меню (`src/components/SiteNav.tsx`, массив `SECTIONS`):

| Раздел в меню | Ключ | Главная страница | Доступ |
|---|---|---|---|
| Счета | `invoices` | `/create` (+ `/history`, `/profile/templates`) | все |
| Kaspi Cashier API | `kaspiApi` | `/kaspi-api` (+ `/kaspi-api/docs`) | все |
| AI-агент | `aiAgent` | `/ai-agent` (8 вкладок) | тариф Про |
| Kaspi Bot | `kaspiShop` | `/kaspi-shop` (14 вкладок) | тариф Про |
| WB Bot | `wildberries` | `/wildberries` | **закрыт для всех** («скоро») |

Не в меню: планировщик салона `/planner/[slug]` (вход по Telegram-QR, отдельная кука
`planner_session`), генератор сайтов салонов `/admin/site-generator` (только админ),
сайты салонов `{slug}.invoices.kz` (переписываются в `src/proxy.ts`).

Вход: Supabase, сессия в `localStorage` браузера, запросы к API с заголовком
`Authorization: Bearer`. Кук-сессии у основного приложения нет.

Лендинг: `/` (счета, основной SEO-адрес, канонический хост без `www`), `/cashier-api`.

## Как откатить по этапам

**Этап 1 (страница `/products` и фильтр меню).** Безопасно откатывается целиком:
`git revert a180917`. Пока человек сам не выбрал продукты на `/products`, меню и так
показывает всё как раньше, так что откат нужен только если страница мешает.
Если нужно только убрать фильтр меню, оставив страницу: в `SiteNav.tsx` заменить
`visibleSections` на `SECTIONS`.

**Wildberries под замком.** Вернуть доступ: удалить `src/app/wildberries/layout.tsx` и убрать
флаг `soon` у записи `wildberries` в `SECTIONS`.

**Этап 2 (единый вход по cookie).** Включается переменной окружения
`NEXT_PUBLIC_SHARED_SESSION=1`; по умолчанию выключен. Откат: убрать переменную и сделать
redeploy. Пока переменной нет, вход работает ровно как раньше.

## Что ещё не начато

Поддомены (`kaspi.`, `api.`, `agent.`, `salon.`, `docs.`), лендинги продуктов, перенос «Счетов»
с корня домена. Перенос «Счетов» — самый рискованный шаг (SEO), делается последним, с
301-редиректами и проверкой в Search Console.
