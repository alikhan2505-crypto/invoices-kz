# 📦 Обновление INVOICES.KZ — АВР и Накладная

## ✅ Что реализовано

### 1. **Переключатель Товар / Услуга на дашборде**
- При создании счёта каждая позиция теперь помечается как **📋 Услуга** или **📦 Товар**
- По умолчанию выбрана **Услуга**
- Данные сохраняются в поле `type: 'service' | 'product'`

### 2. **Акт выполненных работ (АВР) — форма Р-1**
- **Новый файл**: `src/lib/generateAVR.ts`
- **Что делает**: 
  - Генерирует официальный АВР по форме Р-1 (Приложение 50)
  - Берёт **только услуги** из счёта (type === 'service')
  - Если в счёте нет услуг — показывает предупреждение
  - Включает: подписи, печати, НДС расчёт
- **Кнопка**: На странице счёта → "📋 Акт выполненных работ"

### 3. **Накладная на отпуск товара — форма З-2**
- **Новый файл**: `src/lib/generateNakladnaya.ts`
- **Что делает**:
  - Генерирует официальную Накладную по форме З-2 (Приложение 26)
  - Берёт **только товары** из счёта (type === 'product')
  - Если в счёте нет товаров — показывает предупреждение
  - Включает: НДС расчёт, подписи, печати
- **Кнопка**: На странице счёта → "📋 Накладная на отпуск товара"

### 4. **Кнопки на странице счёта**
- Файл: `src/app/invoice/[id]/page.tsx`
- Добавлены 2 новые кнопки рядом с "Коммерческое предложение":
  1. **"📋 Акт выполненных работ"** — генерирует АВР
  2. **"📋 Накладная на отпуск товара"** — генерирует Накладную

---

## 🚀 Как использовать

### 1. Создание счёта
1. На дашборде добавляете услуги/товары
2. Для каждой позиции выбираете:
   - **📋 Услуга** (по умолчанию) — попадёт в АВР
   - **📦 Товар** — попадёт в Накладную
3. Создаёте счёт

### 2. Генерация АВР
1. Открываете созданный счёт
2. Нажимаете "📋 Акт выполненных работ"
3. Вводите:
   - Номер АВР (по умолчанию номер счёта)
   - Номер договора (необязательно)
   - Дату договора
4. Открывается PDF с АВР — можно скачать или распечатать

### 3. Генерация Накладной
1. Открываете счёт
2. Нажимаете "📋 Накладная на отпуск товара"
3. Вводите номер накладной
4. Открывается PDF — можно скачать или распечатать

## 💡 Дополнительные замечания

### НДС
- Все документы (КП, АВР, Накладная) используют настройки НДС из профиля пользователя
- Поддерживаются: **Без НДС**, **НДС 0%**, **НДС 16%**

### Фильтрация
- **АВР** берёт только позиции с `type === 'service'` (или без type — для обратной совместимости)
- **Накладная** берёт только позиции с `type === 'product'`
- Если нет подходящих позиций — показывается предупреждение

### Совместимость
- Старые счета (без поля `type`) будут работать как раньше
- При отсутствии `type` позиции считаются **услугами** (для АВР)
