# invoices.kz: помощник поиска на 1688

Расширение для Chrome. На странице «Калькулятор маржи» (раздел Kaspi Bot) кнопка «Найти товары на 1688»
просит расширение открыть поиск 1688 **в вашем браузере**, прочитать результаты и показать их на странице:
фото, название, цена в юанях и тенге, продажи, магазин, ссылка на товар.

## Установка (один раз)

1. В Chrome откройте `chrome://extensions`.
2. Справа вверху включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension\invoices-1688` из проекта
   (`C:\Users\Abilbayev.Alikhan\invoices-kz\extension\invoices-1688`).
4. Обновите страницу калькулятора маржи. Вместо инструкции в блоке «Товары на 1688» появится кнопка поиска.

После правок кода расширения нажмите на `chrome://extensions` кнопку обновления у этого расширения.

## Как это работает

- Страница invoices.kz отправляет расширению до трёх китайских слов (их подбирает «Найти на 1688»).
- Расширение само строит адрес поиска 1688 (адрес от страницы оно не принимает), открывает его
  во вкладке на заднем плане и читает карточки результатов.
- Если 1688 просит передвинуть ползунок проверки, расширение показывает эту вкладку, **проверку проходите вы**,
  дальше оно продолжает само. Обходить проверку расширение не умеет и не должно.
- Закончив, расширение закрывает вкладку 1688 и возвращает вас на страницу.

## Что оно знает и куда отправляет

- Результаты поиска остаются в вашем браузере и показываются только вам на странице. На наш сервер они **не отправляются**.
- Расширение не читает ваши логины, пароли и cookie, не заходит в аккаунты.
- Права: `storage` и `alarms` (хранить, какой поиск идёт, и сбрасывать его по таймеру), чтение страниц
  `invoices.kz`, `kaspi.invoices.kz` и `s.1688.com/selloffer/`.
- Частота: не чаще одного поиска раз в 3 секунды, одновременно один.

## Файлы

| Файл | Зачем |
| --- | --- |
| `manifest.json` | описание расширения и права |
| `bridge.js` | мост на страницах invoices.kz: принимает просьбу страницы, возвращает события |
| `background.js` | открывает вкладку 1688, следит за ней, возвращает результаты |
| `scrape.js`, `scrape-core.js` | во вкладке 1688: ждёт карточки, при проверке зовёт человека, читает результаты |
| `core.js`, `gbk.js` | проверки запроса и кодировка GBK для адреса поиска 1688 |
| `ext.test.ts` | тесты (запускаются вместе с остальными: `npx vitest run extension`) |

## Если страница 1688 поменяет вёрстку

Расширение вернёт «не удалось прочитать страницу» вместо пустого списка. Поправить селекторы нужно в
`scrape-core.js` (`extractOffers`) и проверить тестом на свежей разметке.
